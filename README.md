# Hotel Booking Prediction

## Présentation du projet

Projet de data science réalisé en Python dans le cadre de ma formation.

L'objectif est d'analyser des données de réservations d'hôtel et d'utiliser des techniques de machine learning pour prédire les annulations de réservation.

Ce projet a été réalisé avec Jupyter Notebook et évalué à **16/20**.

## Fichiers du projet

- `boufnina.ipynb` : notebook contenant le travail réalisé.
- `Hotel Reservations.csv` : jeu de données d'entraînement.
- `Donnees_test.csv` : jeu de données de test.
- `Boufnina.csv` : fichier de résultats.

## Technologies

- Python
- Jupyter Notebook
- Pandas
- Machine learning

## Exécution

1. Télécharger ou cloner le dépôt.
2. Ouvrir le dossier du projet avec Jupyter Notebook.
3. Ouvrir le fichier `boufnina.ipynb`.
4. Exécuter les cellules dans l'ordre.
